# Herramientas y fuentes

- [Guía de acceso a la red local de Chromium](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access): permiso `loopback-network`, `targetAddressSpace` y conexión iniciada por la persona.
- [NetHogs](https://github.com/raboof/nethogs): herramienta opcional para tráfico por proceso.
- [Configuración por archivo de Netlify](https://docs.netlify.com/build/configure-builds/file-based-configuration/): compilación, publicación, redirecciones y cabeceras.
- [FastAPI](https://fastapi.tiangolo.com/), [Uvicorn](https://www.uvicorn.org/), [psutil](https://psutil.readthedocs.io/), [Send2Trash](https://github.com/arsenetar/send2trash), [Pillow](https://pillow.readthedocs.io/): servicio local y miniaturas.
- [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vite.dev/): interfaz web.

Las licencias de dependencias se distribuyen con sus paquetes y metadatos. El código propio de esta entrega no incluye datos personales ni credenciales.
